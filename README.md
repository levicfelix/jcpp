# J-integral LAMMPS

## J-integral calculation for atomic systems using LAMMPS simulations as input

### Requirements

1. C++ compiler
2. Numpy (for plot results)
3. Matplotlib (for plot results)
4. Pandas (for plot results and convert CSV to LAMMPS dump files)

### Reference and Citation

This code was developed and used in the following publication:

Felix et al., Ab Initio Molecular Dynamics Insights into Stress Corrosion Cracking and Dissolution of Metal Oxides, Materials 18, 538 (2025).  
https://doi.org/10.3390/ma18030538

If you use this code in academic work, please cite the publication above and reference this repository.
